# Spot
Spot is a Windows 11 taskbar widget for Spotify.

Spot solves four main problems posed by Spotify's own mini-player:
1. **Spot remembers its size and position between runs.** Spotify does not.
2. **Spot adjusts its position in response to the tray.** Spotify does not.
3. **Spot remains visible on the taskbar.** Spotify does not.
4. **Spot does not require Spotify to be open.** Spotify does.
